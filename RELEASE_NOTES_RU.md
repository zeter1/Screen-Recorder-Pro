# Изменения Windows-сборки

- Windows-бинарник Screen Recorder Pro публикуется как готовый `Screen-Recorder-Pro.exe` на странице GitHub Releases.
- В EXE включены FFmpeg и ffprobe, поэтому для готовой сборки их не нужно устанавливать отдельно.
- Сохранены исправления запуска FFmpeg/NVENC: программа проверяет поддержку опций кодера и корректно классифицирует fallback для `ddagrab`.
- Сохранены постоянные runtime-пути и расширенная стартовая диагностика, чтобы проблемы packaged EXE можно было разбирать по логам.
- Перед публикацией CI запускает regression-проверки и headless smoke-test уже собранного EXE.
- Рядом с бинарником публикуется `Screen-Recorder-Pro.sha256.txt` для проверки целостности.

## Проверка

GitHub Actions подтверждает сборку и headless запуск packaged EXE на Windows runner. Реальная запись экрана, доступность NVENC/GPU, конкретные мониторы и пользовательские аудиоустройства требуют runtime-проверки на целевом компьютере.
